# Q84 Digital

Marketing website for Q84 Digital, a Microsoft Dynamics 365 Business Central consultancy.

A single static page (`index.html`) with hash-based pages: Home, Implementation, Licensing & Pricing, Integrations, Support and Contact. Hosted on GitHub Pages.

## Before launch

1. Replace the placeholder email `hello@q84digital.com`.
2. Connect the contact form to a form service (Formspree, HubSpot or Power Automate). It currently shows a thank-you message without sending anything.
